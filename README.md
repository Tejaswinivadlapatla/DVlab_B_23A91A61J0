## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Tejaswinivadlapatla/DVlab_B_23A91A61J0.git
```

2. Navigate to the project directory

```bash
cd DVlab_B_23A91A61J0
```

3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

4. Launch Jupyter Notebook

```bash
jupyter notebook
```

5. Open any experiment notebook and run all cells.
